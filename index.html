Чистилка

Кэш, временные файлы и прочий хлам Windows

Скачать Чистилку

zip, 13 МБ · Windows 10/11 · установка не нужна

  1. Скачай архив и распакуй его: правой кнопкой → «Извлечь все».
  2. Открой папку Чистилка и дважды кликни Запустить Чистилку.bat.
  3. Если Windows спросит, запускать ли файл из интернета, — нажми «Запустить».

По умолчанию всё удаляется в Корзину, так что промах можно откатить. Личные папки программа не трогает. Python внутри архива свой, на компьютер ничего не ставится.
